# 📝 Task Management REST API (SQLite Persistent Storage)

A clean, beginner-friendly RESTful Task Management API built with **Python 3.11+**, **FastAPI**, and **SQLite3** as part of the **FlyRank Backend Track (Week 3)** assignment.

This project connects the Week 2 REST API to a persistent **SQLite database (`tasks.db`)**, replacing in-memory Python list storage with raw SQL queries (`SELECT`, `INSERT`, `UPDATE`, `DELETE`) while keeping API contracts and responses unchanged.

---

## 🚀 Features

- **Persistent SQLite Storage**: Data persists across application restarts in `tasks.db`.
- **Automatic Database Initialization**: Automatically creates the `tasks` schema and seeds 3 initial tasks if the database is empty.
- **Root & Health Check**: API discovery endpoint (`GET /`) and operational status check (`GET /health`).
- **Full CRUD Operations**:
  - `GET /tasks`: Retrieve all tasks from SQLite.
  - `GET /tasks/{id}`: Fetch a single task by ID.
  - `POST /tasks`: Insert a new task with auto-incremented primary key (`done=False`).
  - `PUT /tasks/{id}`: Update task title and/or completion status in SQLite.
  - `DELETE /tasks/{id}`: Delete a task from SQLite (`204 No Content`).
- **SQL Injection Defense**: Parameterized SQL queries (`?`) for safe database parameter binding.
- **Strict Input Validation**: Rejects empty or missing title payloads with `400 Bad Request`.
- **Interactive Documentation**: Built-in Swagger UI available at `/docs` and ReDoc at `/redoc`.

---

## 💡 Why SQLite Was Chosen

1. **Zero Configuration**: SQLite is a serverless, file-based relational database engine that requires no external database server or daemon running.
2. **Built into Python**: Python includes the `sqlite3` module in its standard library, meaning zero external database driver dependencies.
3. **Persistent & Lightweight**: Perfect for development, desktop applications, testing environments, and lightweight microservices.

## 🗄️ Database Schema (`tasks.db`)

```sql
CREATE TABLE IF NOT EXISTS tasks (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    title TEXT NOT NULL,
    done BOOLEAN NOT NULL DEFAULT 0
);
```

| Column Name | Data Type | Key / Constraints | Description |
| :--- | :--- | :--- | :--- |
| `id` | `INTEGER` | `PRIMARY KEY AUTOINCREMENT` | Unique task identifier auto-generated by SQLite |
| `title` | `TEXT` | `NOT NULL` | Required description of the task |
| `done` | `BOOLEAN` | `NOT NULL DEFAULT 0` | Completion status (`0` = False, `1` = True) |

## ⚡ Quick Start & Installation

### 1. Clone the Repository
```bash
git clone https://github.com/muzml/CRUD_API.git
cd CRUD_API
```

### 2. Create and Activate Virtual Environment
**On Windows (PowerShell):**
```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

**On macOS/Linux:**
```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Install Dependencies
```bash
python -m pip install -r requirements.txt
```

### 4. Run the API Server
```bash
python -m uvicorn app.main:app --reload
```

The server will start at `http://127.0.0.1:8000`. On initial startup, `tasks.db` will be created and seeded automatically with 3 sample tasks.

## 📖 API Documentation & Endpoints

Interactive Swagger UI documentation is available at:
👉 **[http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)**

### Summary of Available Endpoints

| HTTP Method | Endpoint | Description | Expected Status |
| :--- | :--- | :--- | :--- |
| `GET` | `/` | API Metadata & Entrypoint | `200 OK` |
| `GET` | `/health` | Server Health Status | `200 OK` |
| `GET` | `/tasks` | Get all tasks from SQLite | `200 OK` |
| `GET` | `/tasks/{id}` | Get single task by ID | `200 OK` / `404 Not Found` |
| `POST` | `/tasks` | Create a new task in SQLite | `201 Created` / `400 Bad Request` |
| `PUT` | `/tasks/{id}` | Update title and/or status | `200 OK` / `400 Bad Request` / `404 Not Found` |
| `DELETE` | `/tasks/{id}` | Delete task by ID | `204 No Content` / `404 Not Found` |

## 🔍 Database Inspection & Queries (DB Browser for SQLite)

You can view and inspect the `tasks.db` database using GUI tools like **DB Browser for SQLite** or the SQLite CLI.

### Useful SQL Queries

1. **Select All Tasks**:
   ```sql
   SELECT * FROM tasks;
   ```
2. **Count Total Tasks**:
   ```sql
   SELECT COUNT(*) FROM tasks;
   ```
3. **Update Task Completion**:
   ```sql
   UPDATE tasks SET done = 1 WHERE id = 1;
   ```
4. **Delete a Task**:
   ```sql
   DELETE FROM tasks WHERE id = 1;
   ```

## 🧪 cURL Request & Response Examples

### 1. Fetch All Tasks (`GET /tasks`)
```bash
curl -X GET "http://127.0.0.1:8000/tasks"
```

### 2. Create Task (`POST /tasks`)
```bash
curl -X POST "http://127.0.0.1:8000/tasks" \
     -H "Content-Type: application/json" \
```

```bash
curl -X PUT "http://127.0.0.1:8000/tasks/1" \
     -H "Content-Type: application/json" \
     -d '{"done": true}'
```

### 4. Delete Task (`DELETE /tasks/1`)
```bash
curl -X DELETE "http://127.0.0.1:8000/tasks/1"
```
